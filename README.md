# tabligafirstweb
My first Web OS: Self Introductory Page

This is a light weight, browser-based desktop and self-introduction page.


Features:

**Interactive Profile:** A clickable profile picture that pops up my email for contact and a quote.

**Dragabble Clock:** A custom Javascript clock widget that can be dragged across the screen.

**Open/Close Window:** Functional window management handlers built with HTML, CSS and Javascript.


Built with:
- HTML
- CSS
- JavaScript
